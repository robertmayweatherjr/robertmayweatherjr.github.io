3‑2 Milestone Two: Enhancement One

Software Design and Engineering

The artifact I chose to enhance is the main layout file from my Event Tracking App, activity_data_grid, which I originally created in CS 360 Mobile Architect & Programming. This XML file controls the user interface for entering and displaying events. When I first built it, the layout worked but lacked structure, clarity, and the level of professionalism I want to show in my ePortfolio. It relied on fixed sizes, inconsistent spacing, unclear naming, and very little documentation. The screen is central to how users interact with the app, so improving it was a meaningful way to demonstrate growth in software design and engineering.

I included this artifact in my ePortfolio because it highlights my ability to design and refine user interfaces using modern development practices. During the enhancement process, I reorganized the layout into a cleaner and more intuitive flow, added clear XML comments, and replaced fixed dimensions with responsive constraints. I also added input validation attributes to improve usability and renamed several IDs to make the code easier to understand. Updating these IDs required changes in multiple Java files, and fixing those references helped me strengthen the overall structure of the project. These improvements show my ability to produce maintainable, readable, and user‑friendly designs.

The enhancements I completed align with the course outcomes I planned to target during Module One. I demonstrated the ability to deliver professional visual communication by improving the layout’s clarity and responsiveness, which supports Course Outcome Two. I also applied software engineering techniques to refactor and debug the existing code, which supports Course Outcome Four. My original plan for outcome coverage remains accurate, and this work helped me build confidence in both areas.

Working through this enhancement taught me how important consistency and attention to detail are in UI design. Renaming IDs seemed simple at first, but it required careful updates across the entire project to avoid runtime errors. This experience helped me improve my debugging skills and understand how tightly connected layout files and backend logic are in Android development. I also learned how much small improvements, such as adding comments or adjusting spacing, can elevate the overall quality of an application. The main challenge was making sure every reference to the renamed components was updated correctly, but solving those issues helped me grow as a developer. Overall, this enhancement strengthened my understanding of responsive design, defensive programming, and maintainable code structure.
