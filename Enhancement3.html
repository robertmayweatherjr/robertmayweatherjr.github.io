5‑2 Milestone Four: Enhancement Three

Databases

The artifact I selected for enhancement is the DBHelper class from my Event Tracking application, which manages all interactions with the SQLite database. I originally created this component in CS 360 Mobile Architect and Programming, and it serves as the backbone for storing and retrieving user accounts and event information. Revisiting this file during the capstone allowed me to strengthen a core part of the application’s backend architecture and demonstrate my ability to evolve an existing system rather than simply build something new.

I chose to include this artifact in my ePortfolio because it highlights my ability to design and modify a persistent data layer using structured storage. Enhancing the DBHelper allowed me to showcase skills in schema design, data validation, and performance optimization. The improvements I implemented, such as adding a new category field, creating indexes on event name and date, and enforcing validation rules, demonstrate my ability to think critically about data integrity and long‑term maintainability.

These enhancements also show my capacity to refine an existing solution in a way that supports real‑world software engineering practices and strengthens the overall stability of the application. The work I completed aligns directly with the course outcomes I planned to target during Module One. By expanding the database schema, introducing indexing, and updating the supporting code across the application, I met Course Outcome Three, which focuses on developing and modifying computing solutions using appropriate data structures and algorithms.

I also met Course Outcome Four, which emphasizes applying software engineering principles to design, develop, and deliver computing solutions that are reliable and maintainable. Instead of simply adjusting code at the surface level, I applied practices such as defensive programming, schema evolution, and performance tuning, which helped improve the quality and structure of the application’s backend.

Reflecting on the enhancement process, I learned how interconnected different layers of an application truly are. Adding a single new column required updates to the database schema, the model class, the adapter, and the activity responsible for loading and displaying the data. One challenge I encountered was ensuring that the updated constructor in the EventModel class matched the new database structure, since forgetting to add the new parameter initially caused compilation errors.

I also had to be precise when modifying the SQL create table statement, because even a small syntax issue can break the entire database creation process. Working through these challenges strengthened my attention to detail and deepened my understanding of how data flows through an Android application, ultimately improving my confidence in backend development and application architecture.
